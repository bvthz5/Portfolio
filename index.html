SEAT-SYNC ARCHITECTURE & SPECS

Smart Academic Seating & Examination Integrity Management System • Custom-Built for SJCET Palai

Version 2.0.0 Production Ready SJCET Palai Implementation MIT License

SJCET Palai Operational Problem & Proposed Solution

In institutions like St. Joseph's College of Engineering and Technology (SJCET Palai), traditional examination seating relied on manual spreadsheet compilation. This process consumed hours of administrative work, led to human data entry duplicates, created chaotic physical notice board crowding before exams, and frequently seated students from the same department adjacent to each other.

Seat-Sync completely automates this workflow into a single unified platform. It reduces multi-hall seat distribution time from hours to under 800 milliseconds, eliminates student notice board crowding via real-time WebSocket push notifications, and mathematically guarantees zero same-department adjacency.

Dual-Pool Interleaving Matchmaking Engine

Seat-Sync partitions incoming student rosters into distinct departmental pools and executes a dual-pool interleaving matchmaking algorithm. For every bench pair in every exam hall: Department(Seat_Left) ≠ Department(Seat_Right)

SJCET Academic Examination Modules

University End-Semester Module

Campus-wide, multi-hall simultaneous seating execution for KTU end-semester exams with automatic hall capacity throttling and invigilator rosters.

Internal Series Module

Department-level series and midterm exams with subject-wise interleaving, rapid room reallocation, and automated faculty invigilation duty charts.

Unified 3-Tier Portal Architecture

Admin Portal

Room/hall layout configs, CSV batch student ingestion, one-click <800ms allocation, master PDF report export, invigilator duty assignments.

Student Portal

Instant mobile seat lookup (Room, Bench, Seat position), real-time exam schedule, live countdown, and direct hall floor directions.

Invigilator Portal

Digital hall seating chart, instant QR / roll check-in, real-time student attendance verification, and malpractice logging.

Technical Stack & Integrity Guarantees

Built with a modern reactive frontend in React 19 & TypeScript, powered by an asynchronous Express 5 & Node.js micro-backend. Real-time updates utilize a Socket.io event bus, and database durability is enforced via Sequelize ORM v6 running on MySQL with SQLite fallback. Strict foreign-key referential integrity ensures zero orphan allocations or duplicate seats.
